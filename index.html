AMAP-Studio

Unreal Engine 5.8 plugin for importing PMX models and VMD motion and camera data.

Installation

  1. Install AMAP-Studio to your engine from the Fab library, or copy the AMAP-Studio folder into Engine/Plugins/Marketplace or into your project's Plugins folder.
  2. Open your project and enable AMAP-Studio under Edit > Plugins.
  3. Restart the editor when prompted.

Features

  • PMX import - skeleton, materials, morphs, rigid bodies, joints and display frames.
  • SDEF deformation - spherical deformation applied through the Deformer Graph.
  • VMD import - motion data and camera data, the camera imported to a Level Sequence.
  • PMX Bone Solver - IK, append (grant) transforms and twist bones.
  • Twist Position Correction - moves twist bones back onto the line between the joints above and below them.
  • Physics - Bullet-based rigid body, joint and soft body simulation, with an in-editor Physics Editor and a debug visualizer.
  • Parent Constraint - an actor component with Target Actor, Target Bone, Weight and Maintain Offset.
  • Live input - VMC receiver, XR pose input and face-morph input.
  • Motion capture - MetaHuman Animator markerless motion capture workflow from video. Requires the MetaHuman plugin.

Dependencies

Required engine plugins

All of these ship with Unreal Engine 5.8.

IKRig, ControlRigIK Rig and Control Rig assets generated for imported PMX models.
ComputeFramework, DeformerGraphSDEF deformation runs as a Deformer Graph.
ElectraCodecs, AV1DecoderElectra, VPxDecoderElectra, OpusDecoderElectraVideo decoding for the motion capture video ingest step.

Optional plugins

The plugin builds and runs without these. The features listed are unavailable until they are installed.

MetaHuman, ImgMediaRequired only for the MetaHuman Animator markerless motion capture workflow.
VRM4U (third-party, not included)Required only for the MToon Lit, MToon Unlit, Subsurface, Subsurface Profile and Unlit material types.

No other third-party plugin or external application is required. No executable files are bundled.

Network input

The runtime module opens local UDP receivers only while VMC, XR pose or face-mesh input is in use.

Face mesh inputUDP port 39541
VMC receiverUDP port set in the receiver settings

The plugin does not use network replication.
