Unreal Engine 5.8 Production Pipeline

AMAP-Studio

High-fidelity PMX asset import, VMD motion/camera sequencing, real-time SDEF GPU deformation, Bullet physics simulation, and live motion capture in Unreal Engine 5.8.

Quick Start Guide View on GitHub

System Requirements

AMAP-Studio is architected natively for Unreal Engine 5.8 64-bit Windows environments.

Engine VersionUnreal Engine 5.8
Operating SystemWindows 10 / 11 (64-bit)
Target PlatformsWin64 (Editor tools and runtime nodes)
Mac / Linux SupportNot supported (Win64 native optimized)

Installation & Setup

  1. Plugin Deployment

    Install AMAP-Studio directly via the Fab Marketplace library, or copy the AMAP-Studio directory into your project's Plugins/ folder.

  2. Plugin Activation

    Launch your Unreal Engine 5.8 project, navigate to Edit > Plugins, find AMAP Studio under the Animation category, and ensure it is enabled.

  3. Editor Restart

    Restart the editor when prompted. The dedicated AMAP top-level menu will appear in the main editor toolbar.

Seamless Integration: AMAP-Studio is fully embedded into Unreal Engine Slate menus and the asset import pipeline. No external companion executables or background services are required.

Feature Overview

PMX Model Ingestion

Complete skeleton, material mapping, morph target synthesis, rigid body setup, and display frame reconstruction.

SDEF GPU Deformer

Real-time spherical deformation algorithm executed via the Deformer Graph compute framework for skinning integrity.

VMD Sequencing

High-precision import of motion and camera animations directly into Level Sequences with curve fidelity.

Bullet Physics Integration

Dedicated rigid body, constraint joint, and soft body dynamics simulation with in-editor visualizers.

Parent Constraint

Production actor component providing Target Actor, Target Bone, procedural weight interpolation, and offset preservation.

Live Capture & Input

Integrated VMC protocol receiver, XR pose ingest, and markerless MetaHuman Animator video pipeline.

Model & Motion Pipeline

PMX Bone Solver & Correction

The built-in PMX Bone Solver manages Inverse Kinematics (IK), append transform grants, and twist bone stabilization. Twist Position Correction automatically realigns twist bones along the trajectory between upper and lower joint nodes.

VMD Camera Sequencing

VMD camera trajectories are converted into cinematic Level Sequences, binding focal lengths, field-of-view keys, and target track points in Unreal Engine coordinates.

Physics & SDEF Deformation

AMAP-Studio bundles prebuilt static binaries of the Bullet Physics SDK, enabling rigid body collision and soft body cloth/hair simulations alongside standard Chaos physics.

Deformer Graph Prerequisite: SDEF deformation utilizes the engine Compute Framework and Deformer Graph plugins included with Unreal Engine 5.8.
