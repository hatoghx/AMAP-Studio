Unreal Engine 5.8 実装パイプライン

AMAP-Studio

Unreal Engine 5.8 上での高精度 PMX アセット読み込み、VMD モーションおよびカメラのシーケンス化、リアルタイム SDEF GPU 変形、Bullet 物理シミュレーション、ライブモーションキャプチャ環境を提供します。

クイックスタート GitHub を開く

動作環境

AMAP-Studio は Unreal Engine 5.8 の Windows 64 ビット環境に最適化されています。

エンジンバージョンUnreal Engine 5.8
オペレーティングシステムWindows 10 / 11（64 ビット）
対象プラットフォームWin64（エディタツールおよびランタイムノード）
Mac / Linux 対応非対応（Win64 専用の最適化）

インストール手順

  1. プラグインの配置

    Fab マーケットプレイスのライブラリから導入するか、AMAP-Studio フォルダをプロジェクトの Plugins/ フォルダへ配置します。

  2. プラグインの有効化

    Unreal Engine 5.8 でプロジェクトを開き、編集 > プラグイン を開いて Animation カテゴリにある AMAP Studio を有効にします。

  3. エディタの再起動

    ダイアログに従ってエディタを再起動します。メインメニューバーに専用の AMAP メニューが追加されます。

完全統合構造： AMAP-Studio は Unreal Engine の Slate メニューおよびアセットインポート機構に直接組み込まれています。外部 exe やバックグラウンド常駐サービスは不要です。

主要機能

PMX モデル読み込み

スケルトン構造、マテリアル対応、モーフターゲット、剛体設定、表示枠の再構築を完全に実行します。

SDEF GPU デフォーマ

Deformer Graph を通じて球状スキニング補間（SDEF）を GPU 上でリアルタイムに変形処理します。

VMD シーケンス化

モーションおよびカメラアニメーションを高精度にレベルシーケンスへ取り込み、カーブ制御を再現します。

Bullet 物理シミュレーション

剛体、制約ジョイント、ソフトボディのシミュレーションとエディタ内可視化機能を提供します。

Parent Constraint

対象アクター、対象ボーン、重み付けキーフレーム、オフセット保持を備えたコンポーネントです。

ライブキャプチャ入力

VMC プロトコル受信、XR ポーズ入力、MetaHuman Animator を用いた動画モーキャプに対応します。

モデル＆モーション処理

PMX ボーンソルバー＆補正

インバースキネマティクス（IK）、付与親連動、捩りボーンの安定化を自動処理します。捩り位置補正機能により、上下関節の直線上に捩りボーンの位置を正しく再配置します。

VMD カメラシーケンス

カメラの視野角（FOV）、焦点距離、注視点軌道を Unreal Engine の座標系に適合させてレベルシーケンス化します。

物理演算＆SDEF変形

静的リンクされた Bullet Physics 3 SDK を内蔵しており、Chaos 物理と併用して剛体衝突やクロス・ヘア等のシミュレーションを実行できます。

Deformer Graph の要件： SDEF 変形には、Unreal Engine 5.8 に同梱されている Compute Framework および Deformer Graph プラグインが必要です。

ライブ＆ネットワーク入力

ライブキャプチャ機能の実行時のみ、ローカル UDP ソケットを受信ポートとして開放します。

プロトコル／機能既定ポート役割
フェイスメッシュ受信UDP ポート 39541顔面ブレンドシェイプの高頻度受信
VMC モーション受信設定可能 UDP ポート全身トラッキングのリアルタイム同期

エディタメニュー機能

メインメニューバーの AMAP メニューから以下の機能が利用可能です。

項目名機能内容
Twist Position Correction捩りボーンの位置を上下関節の直線上に自動補正します。
Reapply PMX SDEF読み込み済みモデルに対して SDEF 変形アセットを再適用します。
PMX Post-Import Settingsマテリアル適用ルール、法線設定、アセット階層を設定します。
PMX Rig Import SettingsIK 計算精度や Control Rig パラメータの対応関係を設定します。
